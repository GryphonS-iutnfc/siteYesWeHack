# Présentation du projet
Dépôt présentation de l'entreprise YesWeHack dans le cadre de la SAÉ en BUT1 Info à l'IUT de Belfort-Montbéliard. réalisé en HTML/CSS, le site sert a présenter l'entreprise française de bug bounty YesWeHack, le site comprend cinq pages, dont une page d'accueil, une page sur l'économie, l'histoire, les partenaires, et les services de l'entreprise.

## Choix de conception  

En ce qui concerne la conception du site, nous avons demandé a notre client de répondre a deux questionnaires nous permettant de pouvoir personnaliser le site web selon ses besoins, ces choix incluant en partie les couleurs du site (blanc et rouge) ainsi que le style des boutons (ayant une forme carré.
Le style général du site se veut assez lumineux tout en gardant une certaine confiance et un sérieux avec du rouge.
